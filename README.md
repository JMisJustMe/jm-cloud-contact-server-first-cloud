# JM CLOUD CONTACT SERVER v0.4.2

**SERVER FIRST. ROUTES MANY.**

Public-launch package with a single-file phone-safe launch/Ding surface. The same HTML is served at `/` and `/console`; it has no sibling-script dependency.

## Claim boundary
Local phone HTML contact is not a public cloud Ding. A public HTTPS server + external browser signed receipt earns the hosted server/browser Ding only. Physical/app/game/device consequences remain separately claim-gated.

## Deploy
This repository includes `render.yaml` and `deploy/Dockerfile`. Use the separate **JM CLOUD CONTACT DEPLOY RUNNER** to publish this payload and hand it to Render with the minimum owner authority gates.
